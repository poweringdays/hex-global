**built for https://www.roblox.com/games/913614076/Hexaria**

**home page - choose between value searcher and trade calculator or quickly access wiki**

	press G or H to instantly open wiki, number 1 for trade calculator and 2 or enter for value searcher

**value searcher - search names for values**

	/ key to instantly focus onto search

	pressing number 1-10 will instantly collapse the result in the correlating position (enter also works for the 1st result)

	keybind g/h opens wiki for hovered element by default but opens last opened result if nothing is being hovered over

	keybind v/f opens the last opened result

	keybind c key opens the first element

	keybind b key opens the last element

**trade calculator - input multiple items and cards and weigh both sides**

	can open wiki for items by hovering over them and pressing f/g/h

	pressing number 1-4 will instantly open up the search for the coorelated grid

	when choosing item from grid, pressing number such as 1 if its the 1st result in the grid will instantly select it

	if in the selection grid (not search) can instantly close by using keybinds r/enter/backspace
